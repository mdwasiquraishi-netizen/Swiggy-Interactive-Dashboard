# Swiggy-Interactive-Dashboard
## Project Objectives
The main objective of this project is to develop an interactive Power BI dashboard that provides a comprehensive analysis of the Swiggy restaurant ecosystem.

# Dataset
- <a href="https://github.com/mdwasiquraishi-netizen/Swiggy-Interactive-Dashboard/blob/main/swiggy.csv">Swiggy Dataset</a>

# KPI Questions 
1)-What is the overall average rating?
2)-How many restaurants are available in the dataset?
3)-Which restaurants receive the highest number of ratings?
4)-Which restaurants have relatively higher pricing?
5)-Which cities have the highest number of restaurants?
6)-Which cuisines have the highest number of restaurants?
7)-What are the most popular cuisine segments based on restaurant availability?
8)-Which restaurants appear in the higher-price range?

- Dashboard Interaction <a href="https://github.com/mdwasiquraishi-netizen/Swiggy-Interactive-Dashboard/blob/main/Swiggy%20Dashboard.png">View Dashboard</a>

## Insights
1)-The dashboard displays approximately 1M total ratings.
2)-The dashboard contains approximately 9K restaurants.
3)-The displayed average price is approximately 348.44.
4)-Kolkata and Mumbai appear the highest restaurant counts, at approximately 1.3K restaurants each in the displayed ranking.
5)-North Indian cuisine has the highest restaurant representation, with approximately 1,109 restaurants.
6)-Shah Ghouse is the leading restaurant in the displayed "Total Ratings by Restaurant" chart, with approximately 15K ratings, followed by several restaurants around the 10K-rating level

## Conclusions
Overall, this Power BI project demonstrates how raw restaurant data can be transformed into an interactive business intelligence solution that helps stakeholders understand marketplace patterns, compare cities, evaluate restaurant engagement, and identify opportunities for further analysis.
